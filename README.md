# Adventurers Chronicles

Juego de rol para navegadores y celulares.

## Estructura

- `index.html`: pantalla de acceso y entrada al juego.
- `game.html`: cliente del juego.
- `assets/`: sprites, interfaz y audio.
- `css/`: estilos de acceso, juego e interfaz.
- `js/`: configuración, jugador, habilidades, monstruos, interfaz y escenas.
- `php/`: futuro backend de autenticación y personajes.
- `sql/`: futuro esquema de base de datos.

Por ahora, abre `index.html` y selecciona **Jugar como invitado**.
